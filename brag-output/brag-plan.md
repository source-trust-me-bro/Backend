# Brag Plan: KalevaShorts

## What is this app?
A multilingual news newsroom run by AI agents with named humans at the gate: agents read Finnish regional feeds, group the same news into one event, file it in a topic tree, write and translate the story, and a person approves it before readers see it.

## The angle
Not "an app that shows news" but "a newsroom where agents do the work and people keep the keys". Every scene shows a real mechanism from the code: feeds -> events -> topic tree -> review gate -> reader feed -> editor click report -> pricing.

## Hook (0-8s)
"Moved to Oulu? Every headline is in Finnish." over real Finnish headlines taken from the live feeds. Then: "KalevaShorts reads it for you."

## Key moments
- 11 feeds arrive one by one, grouped by outlet; paywalled Kaleva marked "headline only".
- Three outlets report the same news; they collapse into one event, "confirmed" when two independent outlets agree.
- The topic tree grows and related topics get linked (the engine behind related stories).
- A story walks the real five steps, stops at the human gate, and three named reviewer roles approve it.
- The reader feed, with a clearly labelled sponsored box that links to pricing.
- The editor Clicks page: why a story reached which community.

## Outro / punchline
Brand line: "Follow a story across every language it was told in." Then "Money never buys coverage."

## User flow worth showing
Agents collect -> group -> file -> write -> human review -> reader sees it -> editor learns who read it -> revenue from labelled placements.

## Tone
- Preset: polished
- Creative direction: calm product film; the system is the star
- Interpretation: slow reveals, long holds, one idea per scene, restrained sound

## Format: landscape — 1920x1080
## Duration: 90s (user request; the skill default of 15-25s is overridden)

## Audio direction
- Role: warm bed with sparse professional accents
